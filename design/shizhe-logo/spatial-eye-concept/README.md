# SPACE Lab · 空间感知之眼

自由探索版，围绕 Spatial Computing and Embodied Intelligence 的含义设计。

立体框架中的留白形成眼睛般的感知开口，中央蓝色核心代表感知与理解，侧面的蓝色折面强调空间深度。图标与右侧机械臂共同表达对物理世界的感知、建模和行动。

横版使用已修正 C 和 E 的 Shizhe 字标，没有下方小字。

- `space-logo-spatial-eye.png`：透明底横版。
- `space-logo-spatial-eye.svg`：内嵌图像的自包含排版文件，非纯矢量。
- `space-mark-spatial-eye.png`：独立图标。
- `preview-white.png`：白底预览。

图标由内置 imagegen 生成，提示词见 generation-prompt.md。
