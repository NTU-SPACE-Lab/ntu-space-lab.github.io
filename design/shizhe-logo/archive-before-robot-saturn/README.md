# SPACE Lab logo · Shizhe lettering

第 3 页的 Shizhe 方案提供字标。左侧图标以地球网格、轨道和向左侧脸的人像组合，轨道上的节点代表原点。

- `space-shizhe-horizontal.svg` / `.png`：主版，左图标、右侧 SPACE 字标，没有下方小字。
- `space-shizhe-compact.svg` / `.png`：与主版相同，保留供已使用此文件名的场景继续引用。
- `space-shizhe-mark.svg` / `.png`：独立图标。

新版图标使用内置图像生成工具制作，原始图像为 1254 × 1254 px。Shizhe 字标直接保留自原稿。SVG 将图标与字标作为图片嵌入，属于可独立打开的排版文件，并非纯矢量描边。PNG 均为透明背景。

生成提示词见 `generation-prompt.md`。
