# SPACE Lab · 统一几何风格版

图标沿用朝左机器人头、星球和土星环的组合。轮廓改用宽阔圆弧与几何斜切，减少面部和球面细线，并以深海军蓝为主、低饱和钢蓝为辅。图标的视觉高度约为字标的 1.12 倍，以平衡其较多的留白。
