# SPACE Lab · 星球弧光版

星球轮廓由深蓝的厚实弧段过渡到细浅蓝边缘，圆环采用倾斜的椭圆带状结构，以内侧亮边和前后遮挡增加空间感。中央机器人延续朝左侧脸和简洁几何造型。

横向组合沿用 Shizhe 的 SPACE 字标风格，没有下方小字。C 的字母主体重新绘制为上下平行的笔画，机械臂复用原图；E 的中横与左侧圆弧改为连续连接，清除原来的断口与灰色杂影。

- `space-logo-cosmic.png`：3500 × 660 透明底横版，左侧图标较上一版放大约 15%。
- `space-mark-cosmic.png`：透明底独立图标。
- `space-logo-cosmic.svg`：自包含排版文件。C、E 的字母主体为矢量路径，其余字形、机械臂及左侧图标为内嵌位图。
- `wordmark-refined.svg` / `.png`：修改后的独立字标。
- `preview-white.png`：白底预览。

图标使用内置 imagegen 编辑生成，提示词见 generation-prompt.md。
