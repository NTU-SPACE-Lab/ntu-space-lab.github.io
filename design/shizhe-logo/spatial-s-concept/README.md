# SPACE Lab · 折叠空间 S

自由探索版，围绕 Spatial Computing and Embodied Intelligence 的含义设计。

上下两个折叠面呈现空间与深度，连续的轮廓形成 SPACE 的首字母 S。中央蓝色节点代表感知与交互，折叠面的流动关系表达从感知到行动的连接。图标采用与字标接近的深蓝、钢蓝、宽曲面及斜切轮廓。

右侧使用已修正 C 上下笔画及 E 中横连接的字标，无下方小字。

- `space-logo-spatial-s.png`：透明底横版。
- `space-logo-spatial-s.svg`：内嵌图像的自包含排版文件，非纯矢量。
- `space-mark-spatial-s.png`：独立图标。
- `preview-white.png`：白底预览。

图标由内置 imagegen 生成。提示词见 generation-prompt.md。
