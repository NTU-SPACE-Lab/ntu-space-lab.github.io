# SPACE Lab V7 identity

The V7 identity turns a folded spatial continuum into an `S`. Its two inner
planes converge on the red spatial origin, while the wordmark uses the same
terminal cuts, corner radii, and geometric rhythm.

The wordmark incorporates the approved V8 `S`: a continuous single-weight
glyph with a tighter upper bowl and a slightly fuller lower bowl.

All lettering is outlined. The SVG files have no font or external-asset
dependencies.

## Assets

- `space-logo-v7.svg` — primary horizontal lockup for light backgrounds
- `space-logo-v7-mono.svg` — single-ink horizontal lockup; white around the
  origin is a knockout to the substrate
- `space-logo-v7-reversed.svg` — horizontal lockup for navy or dark backgrounds
- `space-mark-v7.svg` — standalone primary mark
- `space-mark-v7-mono.svg` — standalone single-ink mark
- `space-mark-v7-reversed.svg` — standalone mark for dark backgrounds
- `favicon-v7.svg` — small-size-tuned vector favicon
- `favicon-v7-32.png` — 32 px browser fallback
- `apple-touch-icon-v7.png` — 180 px touch icon

## Colours

- Spatial navy: `#080C27`
- Coordinate blue: `#1769FF`
- Origin red: `#D71440`
- Reversed coordinate blue: `#4C91FF`
- Reversed origin red: `#F32250`

## Usage

Use the horizontal lockup at widths of 180 px or larger. Below that size, use
the standalone mark. Keep clear space around the artwork equal to the diameter
of the red origin node. Use the reversed files on dark backgrounds; do not
place the primary artwork directly on photography or other busy imagery.
